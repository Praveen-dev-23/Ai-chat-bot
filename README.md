# Python AI Chatbot

A simple terminal-based AI chatbot built using Python and the OpenAI API. This project allows users to chat with an AI assistant directly from the command line while maintaining conversation history for more natural interactions.

---

## Features

* Real-time AI conversation
* Conversation memory
* Simple terminal interface
* Secure API key management using `.env`
* Error handling support
* Beginner-friendly project structure
* Easy to customize and expand

---

## Technologies Used

* Python
* OpenAI API
* python-dotenv

---

## Project Structure

```bash
ai-chatbot/
│
├── main.py
├── requirements.txt
└── .env
```

---

## Installation

### Clone the Repository

```bash
git clone <your-repository-url>
cd ai-chatbot
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Setup Environment Variables

Create a `.env` file in the root folder:

```env
OPENAI_API_KEY=your_api_key_here
```

Get your API key from the OpenAI Platform.

---

## Run the Project

```bash
python main.py
```
