## 🤖 Python AI Chatbot

A simple AI-powered chatbot built with Python and the OpenAI API. This terminal-based application enables real-time conversations with an intelligent assistant while maintaining chat history for more natural and context-aware interactions.

### ✨ Features

* Real-time AI conversations
* Conversation memory
* Secure API key management using `.env`
* Error handling and stable execution
* Lightweight terminal interface
* Easy to customize and extend

### 🛠️ Technologies

* Python
* OpenAI API
* python-dotenv

### 🚀 Purpose

This project serves as a beginner-friendly introduction to AI application development, demonstrating how to integrate AI models into Python applications and build interactive conversational experiences.
